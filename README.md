- 状态：开发中
- 需求规格文件：[cross-border-appeal-helper-intent-2026-10-31.md](./cross-border-appeal-helper-intent-2026-10-31.md)

## 说明

本仓库为 WorkBuddy 的一个技能（skill），用于跨境售后申诉场景：

- 按对话模式引导用户，逐步确认平台、国家/地区、纠纷类型
- 生成证据清单（evidence checklist）
- 生成提交确认表（submission checklist）
- 起草申诉信（appeal draft）
